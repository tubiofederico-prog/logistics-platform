# LogistiX - Plataforma B2B Ultra Premium de Gestión Logística

Prototipo visual navegable de una **plataforma integral de gestión logística, WMS y torre de control operativa** para operadores portuarios y empresas de logística.

## 🎯 Características Principales

### ✨ Tecnología
- **Next.js 16** con TypeScript
- **React 19** con Server Components
- **Tailwind CSS** para diseño ultra premium
- **Recharts** para gráficos profesionales
- **Lucide React** para iconografía
- Componentes reutilizables y responsivos

### 🎨 Diseño
- Paleta premium: Navy oscuro, Cyan, Azul eléctrico
- Glassmorphism moderado
- Sombras elegantes
- Tipografía moderna
- 100% responsive

## 📦 12 Módulos Principales

1. **Dashboard / Torre de Control** - Resumen operativo en tiempo real
2. **Inventario WMS** - Gestión de inventarios con FIFO
3. **Operaciones Logísticas** - Recepciones, despachos, movimientos
4. **KPIs & Analytics** - Dashboard ejecutivo con gráficos
5. **Alertas y Automatizaciones** - Sistema de alertas inteligente
6. **Incidentes** - Registro y seguimiento de problemas
7. **Documentos Digitales** - Gestión documental sin papel
8. **Portal de Clientes** - Acceso externo para clientes
9. **Mantenimiento** - Control de equipos y recursos
10. **Gestión Humana** - Control de personal y turnos
11. **Configuración** - Parametrización del sistema
12. **Integraciones** - Conexión con otros sistemas

## 🚀 Cómo Ejecutar

```bash
cd logistics-platform
npm install
npm run dev
```

Accede a [http://localhost:3000](http://localhost:3000)
